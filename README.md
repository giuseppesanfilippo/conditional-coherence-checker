# Conditional coherence checker\n\nA Streamlit web application for checking the coherence of finite assessments on conditional events.\n\nThe application accepts events of the form E_i | H_i, their assessed probabilities p_i, and logical relations among the underlying Boolean propositions. It computes the logical constituents and checks coherence using the recursive criterion based on the system Sigma and the set I_0'.\n\n## Features\n\n- Enter conditional events and probabilities through a web form.\n- Enter one logical relation per line.\n- Automatically enumerate the logically possible truth assignments.\n- Group them into logical constituents.\n- Display constituent statuses, points q_k, witnesses, M'_j, and I_0'.\n- Check coherence using linear programming.\n\n## Run locally\n\n    python3 -m pip install -r requirements.txt\n    python3 -m streamlit run web_coherence_app.py\n\nThe app normally opens at http://localhost:8501.\n\n## Boolean syntax\n\nUse and, or, not, and parentheses. The symbols appearing in the event formulas and relations are inferred automatically.\n\nExample:\n\n    E = A\n    H = H1\n\n    not (A and B)\n    H1 or H2\n\n## Deployment\n\nThe app can be deployed from GitHub using Streamlit Community Cloud. Select web_coherence_app.py as the main file. The dependencies are listed in requirements.txt.\n\n## License\n\nNo license has been specified yet.
